# QuBIOS performance

The v1.0.0 numbers that used to be on this page were **not measurements**. They came from a hard-coded formula (p_L = 21·p²) and from local simulations that were described as IBM hardware runs. They have been withdrawn.

Measured results for v1.1.0:
- **Simulation:** see the README and `benchmarks/results/steane_memory.json` (reproduce with `python benchmarks/steane_memory.py`)
- **Real IBM hardware:** produced by `hardware/ibm_steane_test.py`; each result file contains the IBM job ID
